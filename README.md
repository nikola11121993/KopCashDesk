# Учет доходов

Отдельная настольная система для учёта и сверки кассовой выручки. C# / .NET 10 / WPF / SQLite. Проект не изменяет старый `C:\BOT`.

## Первая предварительная версия 0.1.0

Это начальная рабочая оболочка, а не готовая система автоматической сверки. Реализованы пустая локальная база, создание и редактирование организаций и торговых точек, поиск, контекстные меню, навигация, журнал, резервная копия и справка. Внутренняя модель предусматривает фискальные и банковские операции с точными суммами и защитой от повторных внешних идентификаторов.

Подключения Такском, Астрал ОФД и почты пока являются профилями настроек. Реальная авторизация, получение чеков, загрузка email-вложений, сводные отчёты и сверка ещё не реализованы. Кнопка проверки честно сообщает об отсутствии сетевого адаптера. Секретные ключи пока вводить не нужно; не вставляйте их в JSON или GitHub.

## Как открыть программу

1. Откройте раздел Releases в этом приватном репозитории и скачайте `UchetDohodov-win-x64.zip` из предварительного релиза, когда он успешно опубликован.
2. Распакуйте архив в отдельную папку, например `C:\UchetDohodov`. Не распаковывайте в `C:\BOT`.
3. Запустите `UchetDohodov.exe`. Пакет self-contained включает необходимые компоненты .NET 10; отдельная установка SDK не требуется.
4. При первом запуске создаётся новая пустая база в `%LOCALAPPDATA%\KopCashDesk\cashdesk.db`. Реальные данные и ключи в поставку не включены.
5. Добавьте организацию, затем торговые точки. Правый щелчок по строке открывает контекстное меню, двойной щелчок — редактирование. F1 открывает помощь.
6. В разделе «Настройки» можно создать резервную копию базы. Перед обновлением сохраняйте её отдельно от папки программы.

Рабочие данные по-прежнему хранятся в `%LOCALAPPDATA%\KopCashDesk\cashdesk.db`, чтобы обновление не потеряло существующую базу. Внутренние имена проекта также пока сохранены для совместимости.\n\nПрограмма пока не подписана цифровой подписью. Не отключайте антивирус ради запуска. Если Windows предупреждает о неизвестном издателе, проверяйте происхождение файла через приватный репозиторий и результаты сборки.

## Разработка

Откройте `KopCashDesk.slnx` в Visual Studio с поддержкой .NET 10 и Desktop development with .NET либо используйте команды:

```powershell
dotnet restore KopCashDesk.slnx
dotnet build KopCashDesk.slnx -c Release
dotnet test tests/KopCashDesk.Tests/KopCashDesk.Tests.csproj -c Release
dotnet publish src/KopCashDesk.Desktop/KopCashDesk.Desktop.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

Сборка проверяется GitHub Actions на Windows. Бинарные файлы публикуются отдельно от исходников. Если квота Actions artifacts исчерпана, это не означает успешной доставки приложения; приватный preview release используется как резервный канал после успешного CI.

Состав: `Core` — модель и правила; `Data` — SQLite; `Desktop` — WPF; `Tests` — автоматические тесты. Подробное задание и этапы — в `docs/PROJECT.md` и `docs/ROADMAP.md`.

## Безопасность и ограничения

Не добавляйте в репозиторий пароли, токены, сертификаты, реальные кассовые базы и банковские реестры. Не используйте предварительную версию для финансовой отчётности. Фискальные коррекции и банковские возвраты не выполняются автоматически. API подключаются только по официальной документации и с разрешённым доступом.
